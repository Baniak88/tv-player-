# Android 0.9.22 — responsive port

This module keeps the dark Fire Stick 0.9.16 visual style, with Android-specific portrait/landscape layouts and touch input. The portrait bouquet button opens a searchable list, with group selection preserved across playback and rotation. Playback options use a width-bounded scrollable dialog based on Android 1.1.6, rather than a 420 dp TV side panel. It builds `pl.tvplayer.preview` with versionCode 39 and the existing preview signing key. The original `:tv` module and `app/src/main` stay byte-for-byte unchanged in Git relative to TV commit `67fa2975945dc4a92400c568ac855596e93e4a98`.

Android variants live in `src/main/java/pl/tvplayer`: `TvActivity`, `TvShelfView`, `MovieActivity`, `SeriesActivity`, `PlayerActivity`, `TvLiveInfoBar` and `PlaybackNetwork`. They are based on the original TV/shared classes and contain phone layout, rotation and transport changes. `syncAndroidSharedSources` copies all remaining shared Java classes into a generated build directory, excluding those variants to avoid duplicate classes. The Android manifest belongs to this module and uses fullSensor so the accelerometer rotates every screen even with the system rotation lock enabled.

`AndroidApplication` supplies single-tap behavior, previous/next channel arrows that hide after five seconds and optional toolbar actions. `AndroidLayout` handles narrow layouts and window insets. `AndroidHttpSource` follows HTTP/HTTPS redirects, makes at most one platform-agent compatibility fallback for HTTP 403/406, and can satisfy a rejected small range by skipping at most 2 MiB with a 15-second skip budget. Large rejected ranges remain errors rather than downloading an entire movie repeatedly. AndroidLoadErrorPolicy retries a first HTTP 458 after five seconds, or later if Retry-After requests up to 30 seconds. For an already playing VOD, a terminal 458 can trigger one delayed reopen of the original media item at its current position. Another automatic reopen requires a minute of continuous playback. Long server delays are respected. `PlayerActivity` shows the actual HTTP code and offers an explicit restart for an invalid resume position.

Verification: shared JVM tests, Android Lint, original TV source fingerprint, signature/package/launcher checks, eight playback recovery tests, twelve touch/rotation cases and nine HTTP policy and transport cases on API 35. The TLS fixture installs a temporary certificate factory only in the test process and restores it afterwards; the shipped app retains platform certificate validation.

The rotation cases run with system auto-rotate disabled and inject actual accelerometer vectors through the emulator console. The CI-only `scripts/android-rotation-server.py` bridge listens on host loopback, reached by the emulator at `10.0.2.2:8769`; the smoke script starts and stops it. Tests do not force Activity orientation or change the user rotation to simulate a physical turn. They also verify a searchable M3U bouquet list, return from playback, and an open options dialog rotating without clipping.

Build with `gradle :android:assembleDebug :android:assembleDebugAndroidTest`. The preview APK is `android/build/outputs/apk/debug/android-debug.apk`. Changes in this module are not included in the Fire Stick APK.
